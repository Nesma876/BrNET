# Machine-readable supplementary tables

This directory contains only the current machine-readable support files:

- `canonical_reported_values.csv`: document-control values used in the revision;
- `figure3_selected_pairs.csv`: exact pHash pairs shown in the illustrative figure;
- `fold_seed_brnet.csv`: BrNet fold-by-seed results;
- `fold_seed_mobilenetv2_efficientnetb7.csv`: complete CNN baseline fold-by-seed results.

Submission-format LaTeX and incomplete historical run summaries are intentionally excluded from this reviewer repository.
